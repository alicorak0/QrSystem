Program.cs içinde yapılan değişikliklerin özeti:

1. Rate Limiting yapılandırması eklendi.
   - Microsoft.AspNetCore.RateLimiting kullanıldı.
   - SlidingWindowRateLimiterOptions ile limitler tanımlandı.
   - options.GlobalLimiter, options.AddPolicy("high"), options.AddPolicy("medium"), options.AddPolicy("low") yapılandırıldı.
   - RejectionStatusCode 429 Too Many Requests olarak ayarlandı.

2. IP + kullanıcı bazlı anahtar oluşturuldu.
   - Giriş yapmış kullanıcılar için key: IP:username
   - Anonim kullanıcılar için key: IP:anon
   - Böylece aynı IP altındaki farklı kullanıcılar ayrı limitlere tabi tutuluyor.

3. Cloudflare / reverse proxy uyumluluğu sağlandı.
   - X-Forwarded-For ve X-Forwarded-Proto başlıkları dikkate alındı.
   - app.UseForwardedHeaders(...) ile gerçek istemci IP adresi alınıyor.

4. 4 katmanlı rate limit politikası oluşturuldu.
   - Global: 100 request / dakika, SegmentsPerWindow = 6, QueueLimit = 0
   - High: 15 request / dakika, QueueLimit = 0
   - Medium: 200 request / dakika, QueueLimit = 20
   - Low: 10 request / dakika, QueueLimit = 0

5. Middleware sıralamasına rate limiter eklendi.
   - app.UseRateLimiter() çağrısı eklendi.
   - app.UseForwardedHeaders() çağrısı eklendi.

Bu sayede API, hem IP hem kullanıcı bazlı olarak limitleniyor, Cloudflare üzerinden gerçek IP kullanıyor ve 429 hatası dönecek şekilde yapılandırılmış oldu.
